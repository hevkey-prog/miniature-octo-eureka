# miniature-octo-eureka — เว็บอัพรูปส่วนตัว

เว็บไซต์ส่วนตัวสำหรับอัพโหลดและแสดงรูปภาพ รันบนคอมพิวเตอร์ของคุณเองเป็นเซิร์ฟเวอร์ ใช้ Node.js + Express เก็บไฟล์รูปไว้ในเครื่อง ไม่ต้องพึ่งบริการภายนอก

## ฟีเจอร์

- หน้าล็อกอินด้วยรหัสผ่านเดียว (ตั้งค่าเองผ่าน `.env`) ป้องกันคนอื่นเข้ามาดู/อัพโหลดรูป
- อัพโหลดรูปภาพ (jpg, png, gif, webp, heic) ไม่เกิน 20MB ต่อไฟล์
- แกลเลอรีแสดงรูปทั้งหมด เรียงจากใหม่ไปเก่า พร้อมปุ่มลบ
- ไฟล์รูปเก็บอยู่ในโฟลเดอร์ `uploads/` บนเครื่องของคุณเอง

## วิธีติดตั้งและรัน

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
git clone <repo-url>
cd miniature-octo-eureka
npm install
cp .env.example .env
```

แก้ไขไฟล์ `.env` เพื่อตั้งรหัสผ่านของคุณเอง:

```
PORT=3000
ADMIN_PASSWORD=ตั้งรหัสผ่านของคุณ
SESSION_SECRET=สุ่มข้อความยาวๆ อะไรก็ได้
```

จากนั้นเริ่มเซิร์ฟเวอร์:

```bash
npm start
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` แล้วล็อกอินด้วยรหัสผ่านที่ตั้งไว้

## ใช้คอมพิวเตอร์ของคุณเป็นเซิร์ฟเวอร์จริง

รันตามขั้นตอนด้านบนแล้วเว็บนี้จะทำงานอยู่บนเครื่องคุณ ถ้าต้องการให้เข้าถึงได้จากอุปกรณ์อื่น มีทางเลือกดังนี้:

1. **ใช้ในบ้าน/วง LAN เดียวกัน** — หาค่า IP ของเครื่อง (เช่น `192.168.1.10`) แล้วเข้าเว็บผ่านอุปกรณ์อื่นในวง Wi-Fi เดียวกันด้วย `http://192.168.1.10:3000`
2. **เข้าถึงจากอินเทอร์เน็ตแบบง่ายและปลอดภัยกว่า** — ใช้บริการ tunnel เช่น [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) หรือ [Tailscale](https://tailscale.com/) ทำให้ไม่ต้องเปิดพอร์ตที่เราท์เตอร์โดยตรง
3. **Port forwarding บนเราท์เตอร์** — เปิดพอร์ต 3000 ชี้มาที่เครื่องคุณ วิธีนี้ทำได้แต่มีความเสี่ยงด้านความปลอดภัยสูงกว่า ควรเปลี่ยนรหัสผ่านให้แข็งแรงและพิจารณาใช้ HTTPS (เช่นผ่าน reverse proxy อย่าง Caddy หรือ Nginx) ก่อนเปิดสู่สาธารณะ

**ข้อควรระวัง:** เว็บนี้ทำเพื่อใช้งานส่วนตัวเบื้องต้น ยังไม่มีการเข้ารหัส HTTPS ในตัว และมีผู้ใช้เดียว (รหัสผ่านเดียว) หากจะเปิดให้เข้าถึงจากอินเทอร์เน็ตจริง แนะนำให้ใช้ tunnel service ที่มี HTTPS ให้ในตัว (เช่น Cloudflare Tunnel) แทนการเปิดพอร์ตตรงๆ

## โครงสร้างโปรเจกต์

```
server.js        เซิร์ฟเวอร์หลัก (Express)
views/           หน้าเว็บ (EJS templates)
public/          ไฟล์ CSS
uploads/         รูปภาพที่อัพโหลด (ไม่ถูก commit เข้า git)
```
